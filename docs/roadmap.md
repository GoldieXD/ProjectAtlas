# Atlas Roadmap

This roadmap aligns with the development plan in the main Atlas software design specification.

## Milestone 1
- Project initialization
- GitHub repository setup
- Next.js and TypeScript foundation
- Tailwind and UI setup
- Supabase connection and authentication
- Basic layout and deployment pipeline

## Milestone 2
- Portfolio CRUD
- Watchlist CRUD
- Database models
- Dashboard widgets
- Portfolio calculations
- Company search

## Milestone 3
- Market event ingestion
- News ingestion
- Basic decision engine
- Insight generation and storage
- Dashboard integration

## Milestone 4
- Morning Brief generation
- Daily summaries
- Economic calendar
- Earnings integration

## Milestone 5
- AI assistant
- Context-aware prompts
- Portfolio awareness
- Insight explanations
- Educational responses

## Milestone 6
- Bug fixing
- Performance improvements
- UI polish
- Accessibility review
