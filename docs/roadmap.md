# Atlas Roadmap

This roadmap aligns with the development plan in the main Atlas software design specification.

## Milestone 1
- Project initialization
- GitHub repository setup
- Next.js and TypeScript foundation
- Tailwind and UI setup
- Supabase connection and authentication
- Basic layout and deployment pipeline

Current evidence: project initialization, the Next.js and TypeScript foundation,
frontend CI, and the basic responsive application layout have implementations.
The Issue #5 layout is a presentation-only shell with unavailable placeholders;
it is not evidence that authentication, Supabase, Prisma, database integration,
deployment, or any routed product feature is complete. Human approval is still
required before the shell is merged.
