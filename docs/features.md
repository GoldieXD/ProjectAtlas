# Atlas Features

This document summarizes the core feature set for Atlas and mirrors the MVP scope defined in the main software design specification.

## MVP Feature Areas

### Authentication
- Account registration
- Login and logout
- Password reset
- Email verification

### Portfolio
- Add, edit, and delete holdings
- Portfolio performance tracking
- Gain/loss visibility
- Allocation overview

### Watchlist
- Add and remove securities
- Search securities
- View watchlist

### Dashboard
- Portfolio summary
- Morning Brief
- Top insights
- Upcoming earnings and economic events
- Recent alerts

### Morning Brief
- Daily summary
- Portfolio update
- Top market events
- Priority insights
- Risks and opportunities
- Learning moments

### Insights
- Personalized ranking
- Explainable reasoning
- Source links
- Related holdings
- Confidence scores

### AI Assistant
- Explain news, holdings, concepts, and market events
- Answer questions with portfolio context
- Reference the user's portfolio

### Search and Company Pages
- Search companies and tickers
- View company details, recent news, and AI summaries

## Out of Scope for V1

- Broker integration
- Trading or buy/sell recommendations
- Social or community features
- Crypto wallets
- Desktop or native mobile apps
